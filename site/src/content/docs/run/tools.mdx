The tools Claude can call through the connector: octagon-mcp {platform.connectorVersion},
{platform.toolCount} tools ({platform.readTools} read-only, {platform.writeTools} that can write) and
{platform.promptCount} prompts. Arguments marked `*` are required. The tags link to the
[commands](/use/commands/) that use each tool.

:::note[Generated from source]
Built from the `TOOLS` and `PROMPTS` arrays in
[`supabase/functions/octagon-mcp/index.ts`](https://github.com/ollielarkins/octagonanalytics-reverse/blob/main/supabase/functions/octagon-mcp/index.ts)
on every build. Descriptions are the ones Claude reads, lightly trimmed. "Can write" is inferred
from the description, so a tool that both reads and writes (such as `off_limit`) shows as "Can
write". Every tool also accepts `auth_token`, omitted here.
:::
