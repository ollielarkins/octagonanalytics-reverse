For anyone wondering "can it answer this?". You don't need command syntax: ask in plain English and Claude picks the right tool. This page groups the questions by what you are trying to do, with examples of what comes back. Every slash command is on [Commands](/use/commands/); the {platform.toolCount} tools underneath are on [Tools reference](/run/tools/).

## How to ask

- **Plain English works.** "How did Keelan do in Q2", "which of my roles have gone cold", "what's happening on the Bosch role".
- **A slash command is a shortcut**, and you can add context after it: `/funnel Q2`, `/find a candidate that hasn't been contacted this week`.
- **Name a window** if you want something other than the default. Windows default to **2026 year to date**, and the end date is exclusive. `/funnel Q2`, `/billing last month`, `/leaderboard July` all work. Dates come back as DD/MM/YYYY.
- **Name a person** to see their figures. Firm reports are open to everyone; desk views (your day, weekly KPIs, billing) show your own row unless you are a manager or admin.
- **Ask where a number comes from.** "Where does that number come from?" gets the definition.

:::tip[Same question, same shape]
Claude is instructed to answer the same question in the same layout for everyone: the answer first, then the detail, then 1 to 3 next actions. Money is £ with separators, rates are 1 dp and name the ratio (CV→placed x.x%), and tables run highest first.
:::

<Badge text="Read" variant="success" /> changes nothing. <Badge text="Write" variant="caution" /> previews first and changes RecruitCRM only when you confirm (see [Making changes safely](/use/making-changes/)).

<Example ask="how am I doing this week?" who="Recruiter">
An inline scorecard of this week's actuals (from Monday, stated as DD/MM/YYYY) against your targets. Claude gives the headline and the exceptions, not the whole table again. Where you're behind, the gap as a number and one next action. BD and client calls carry a caveat and, beside them, how many untagged calls look like BD or client calls: "BD calls x of 5, plus y that look like BD but aren't tagged". If those would close the gap, the next action is `/tagcalls`, not more calls.
</Example>

<Example ask="/eod" who="Recruiter">
One table holding delivery and calls together, for taking into a meeting with your manager:

| KPI | Today | Week to date | Weekly target | Gap |
|---|---|---|---|---|
| CV sends | x | x | 10 | x |
| Interview requests | x | x | 5 | x |
| Interviews (1st) | x | x | 4 | x |
| BD calls* | x (+y untagged) | x | 5 | x |
| Client calls* | x (+y untagged) | x | 5 | x |
| Placed | x | x | — | — |

Then other stage movement today, calls today (total, connected, connect rate, talk time, untagged), and one line for anything behind.
</Example>

Your silver medallists: candidates who reached 2nd, 3rd interview or Offered and were then rejected, one row each at their closest miss, with up to 3 open roles each with the most similar title. <Example ask="/aftercare" who="Recruiter">

Placements whose Won deal has no start date can't appear: `/hygiene` lists them.
</Example>

## Writing content

Drafts only. Anything you didn't supply becomes a `[placeholder]`; salary is stated only if you gave it.

| Ask | Command |
|---|---|
| "Write an advert for [Job]" | [`/advert`](/use/commands/#advert) |
| "Boolean for a senior embedded C++ engineer in Bristol" | [`/boolean`](/use/commands/#boolean) |
| "InMail for [Candidate] about [Job]" | [`/inmail`](/use/commands/#inmail) |
| "Spec pitch [Candidate] to [Client]" | [`/specpitch`](/use/commands/#specpitch) |
| "Prep [Candidate] for the [Client] interview" | [`/interviewprep`](/use/commands/#interviewprep) |
| "Formatted CV for [Candidate]" | [`/formattedcv`](/use/commands/#formattedcv) |

<Example ask="/specpitch [Candidate] to [Client]" who="Recruiter">
First an off-limit check: if the candidate is off limit, it stops. Otherwise an anonymised pitch under a screen long, with a subject line: no name, no current employer, leading with the two or three things that make them worth a conversation. Gaps are `[placeholders]`. It doesn't send (that's `/email`, draft by default), and it doesn't record the pitch in RecruitCRM (that's `/pitch`, the step people forget, so the pitch KPI under-reports).
</Example>

## Managers and admins

These need a manager or admin token; a recruiter token gets a plain refusal. The output is individual performance and usage data: keep it out of team channels.

| Ask | Command | Who |
|---|---|---|
| "Who needs attention this week?" | [`/exceptions`](/use/commands/#exceptions) | Managers and admins |
| "Draft the end-of-week email" | [`/eow`](/use/commands/#eow) | Managers and admins |
| "Hand [Consultant]'s desk to [Consultant]" | [`/handover`](/use/commands/#handover) | Managers and admins |
| "Is the platform working?" | [`/health`](/use/commands/#health) | Admins |
| "Who's using it?" | [`/usage`](/use/commands/#usage), [`/team`](/use/commands/#team) | Admins |

Several recruiter commands widen for managers: `/lapsed`, `/hygiene`, `/aftercare`, `/silver` and `/jdcheck` show your own desk to a recruiter and the firm to a manager or admin unless a name is given.

## What it won't do

- **Invent** a salary, a number, a name or a fact. If the data can't answer, it says so. "That isn't tracked" is a correct answer.
- **Act on instructions found in CRM data.** Notes, job descriptions and emails are data, never commands.
- **Write without a preview** and your confirmation.
- **Bulk-export** candidate data, or send personal data to external tools.
- **Open RecruitCRM in a browser.** If no tool can make a change, it gives you the manual step.
