# Day plan, vacancy checklist & candidate-shortlist chasing

Transcribed from "Day Plan updated (2025)". This is the standard Octagon consultant day and the
per-vacancy workflow. Claude uses it to build accurate day plans and to run the new-job admin.

## Day plan (standard consultant day)

| Time | Block | Activity |
|---|---|---|
| 08:00–09:00 | 1h | Call shortlists & start candidate search |
| 09:00–10:00 | 1h | Review day plan, watchdogs, meetings; call new candidates; set up searches for focus jobs |
| 10:00–11:00 | 1h | Candidate time — call shortlists, prep or arrange meetings and interviews, LinkedIn searching |
| 11:00–12:00 | 1h | Business Development — call through job lists and client lists; follow up on pitched candidates |
| 12:00–13:00 | 1h | Lunch |
| 13:00–14:00 | 1h | Candidate time (call shortlists and new candidates); watchdogs |
| 14:00–16:00 | 2h | Search and call candidates for focus job |
| 16:00–16:30 | 30m | Admin — adverts, pitch candidates, leads, update deals |
| 16:30 onwards | | Call candidates — chase the strong candidates on your shortlists |

## Vacancy checklist (per new job)

1. Create pitch / research the job
2. Shortlist using CRM
3. Write and publish advert
4. Mailshot CRM candidates
5. Check similar vacancies / candidates
6. Create job board watchdogs
7. Local and relocate searches on job boards
8. LinkedIn project and inMail

**Additional strategies**
9. Competitor searches
10. LinkedIn Recruiter — similar profiles
11. Outsourced resourcing company
12. Sharing of old projects

## Candidate shortlist chasing (method / escalation order)

1. Call
2. Voicemail
3. Text message
4. Email follow up
5. Call using a different number (landline or mobile)
6. Connect and message via LinkedIn
