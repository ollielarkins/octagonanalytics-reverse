# Octagon Analytics (retired plugin)

This plugin was never installed by anyone and no longer ships. The commands are in the
[octagon-plugins](https://github.com/ollielarkins/octagon-plugins) repo, in four plugins; see
[COMMANDS-MOVED.md](COMMANDS-MOVED.md) for why. The full list is on the wiki's
[Commands](https://github.com/ollielarkins/octagonanalytics-reverse/wiki/Commands) page.

`.mcp.json` and `hooks/` stay here as the record of how the connector and the session-start
dashboard hook are configured.
