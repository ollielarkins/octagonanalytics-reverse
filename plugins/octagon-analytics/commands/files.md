---
description: List the files attached to a candidate, job or company in RecruitCRM.
---

Usage: `/files Jamie Adams`

Call `files_list` for the record. Present file name, type and date (DD/MM/YYYY), newest first.

This tells you **what exists**, not what is in it. Do not describe or summarise a CV you have not
been given the contents of — if the recruiter needs the detail, they open the file.

Useful for checking whether a CV is actually on file before sending one out, or whether a signed
terms document exists for a client.

If nothing is attached, say so plainly. A candidate with no CV on file is a real gap worth
flagging, particularly if they are at CV Sent or beyond.

File names can contain candidate names: PII, internal only.
